## 3단계로 시작하기

Huny API를 사용하여 첫 번째 요청을 보내는 방법을 단계별로 안내합니다.

## Step 1: API 키 발급

<Steps>
<Step title="대시보드 접속">
  [Huny API 대시보드](https://api.huny.dev/dashboard)에 로그인하세요.
  
  <Info>
  아직 계정이 없으신가요? 대시보드에서 무료로 계정을 생성할 수 있습니다.
  </Info>
</Step>

<Step title="API 키 생성">
  1. 대시보드의 "API Keys" 섹션으로 이동하세요.
  2. "새 API 키 생성" 버튼을 클릭하세요.
  3. 키 이름을 입력하고 권한을 선택하세요.
  4. 생성된 API 키를 안전한 곳에 복사해 보관하세요.
  
  <Warning>
  API 키는 한 번만 표시됩니다. 잃어버리면 새로 생성해야 합니다.
  </Warning>
</Step>
</Steps>

## Step 2: 첫 API 호출

이제 API 키를 사용하여 첫 번째 요청을 보내보겠습니다.

### 사용자 목록 조회

가장 간단한 엔드포인트인 사용자 목록 조회부터 시작하세요.

<CodeGroup>
```bash cURL
curl -X GET 'https://api.huny.dev/v1/users' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json'
```

```javascript Node.js
const fetch = require('node-fetch');

const response = await fetch('https://api.huny.dev/v1/users', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  }
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

headers = {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
}

response = requests.get('https://api.huny.dev/v1/users', headers=headers)
data = response.json()
print(data)
```

```javascript JavaScript (Fetch API)
const response = await fetch('https://api.huny.dev/v1/users', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  }
});

const data = await response.json();
console.log(data);
```
</CodeGroup>

## Step 3: 사용자 생성

이제 POST 요청을 사용하여 새 사용자를 생성해보겠습니다.

<RequestExample>
```bash cURL
curl -X POST 'https://api.huny.dev/v1/users' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "email": "newuser@example.com",
    "name": "새 사용자",
    "password": "secure_password_123"
  }'
```
</RequestExample>

<ResponseExample>
```json Success Response
{
  "data": {
    "id": "usr_9876543210",
    "email": "newuser@example.com",
    "name": "새 사용자",
    "created_at": "2024-01-15T11:00:00Z",
    "updated_at": "2024-01-15T11:00:00Z"
  }
}
```
</ResponseExample>
