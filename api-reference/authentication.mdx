## 인증 개요

Huny API는 Bearer 토큰 기반 인증을 사용합니다. 모든 API 요청에는 유효한 API 키가 필요합니다.

## API 키 발급

API 키는 [대시보드](https://api.huny.dev/dashboard)에서 발급받을 수 있습니다.

<Steps>
<Step title="대시보드 로그인">
  [Huny API 대시보드](https://api.huny.dev/dashboard)에 로그인하세요.
</Step>

<Step title="API 키 생성">
  1. 대시보드의 "API Keys" 섹션으로 이동하세요.
  2. "새 API 키 생성" 버튼을 클릭하세요.
  3. 키 이름과 권한을 설정하세요.
  4. 생성된 키를 안전한 곳에 복사해 보관하세요.
</Step>
</Steps>

<Warning>
  API 키는 한 번만 표시됩니다. 잃어버리면 새로 생성해야 합니다.
</Warning>

## 인증 헤더

모든 API 요청의 `Authorization` 헤더에 Bearer 토큰을 포함해야 합니다.

### 헤더 형식

```http
Authorization: Bearer YOUR_API_KEY
```

### 예시

<CodeGroup>
```bash cURL
curl -X GET 'https://api.huny.dev/v1/users' \
  -H 'Authorization: Bearer sk_live_1234567890abcdef'
```

```javascript JavaScript
const response = await fetch('https://api.huny.dev/v1/users', {
  headers: {
    'Authorization': 'Bearer sk_live_1234567890abcdef'
  }
});
```

```python Python
import requests

headers = {
    'Authorization': 'Bearer sk_live_1234567890abcdef'
}
response = requests.get('https://api.huny.dev/v1/users', headers=headers)
```

```php PHP
<?php
$ch = curl_init('https://api.huny.dev/v1/users');
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    'Authorization: Bearer sk_live_1234567890abcdef'
]);
$response = curl_exec($ch);
curl_close($ch);
?>
```
</CodeGroup>

## API 키 유형

### 테스트 키 (Test Keys)

- 접두사: `sk_test_`
- 프로덕션 데이터에 영향을 주지 않습니다.
- 개발 및 테스트 환경에서 사용하세요.

### 프로덕션 키 (Live Keys)

- 접두사: `sk_live_`
- 실제 프로덕션 데이터에 접근합니다.
- 신중하게 관리하세요.

## 인증 오류

인증이 실패하면 `401 Unauthorized` 상태 코드와 함께 다음 형식의 에러를 반환합니다:

<ResponseExample>
```json Error Response
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "유효하지 않은 API 키입니다.",
    "details": {
      "reason": "API 키가 만료되었거나 존재하지 않습니다."
    }
  }
}
```
</ResponseExample>

## 보안 모범 사례

### API 키 보관

<Tip>
  API 키를 안전하게 보관하세요:
  - 환경 변수에 저장
  - 버전 관리 시스템에 커밋하지 않기
  - 공개 저장소에 노출하지 않기
</Tip>

### 환경 변수 사용 예시

<CodeGroup>
```bash .env
HUNY_API_KEY=sk_live_1234567890abcdef
```

```javascript JavaScript
const apiKey = process.env.HUNY_API_KEY;
```

```python Python
import os
api_key = os.getenv('HUNY_API_KEY')
```

```ruby Ruby
api_key = ENV['HUNY_API_KEY']
```
</CodeGroup>

### 키 순환

정기적으로 API 키를 순환(교체)하여 보안을 강화하세요:

1. 새 API 키를 생성하세요.
2. 애플리케이션에서 새 키로 업데이트하세요.
3. 이전 키를 비활성화하세요.

<Warning>
  키를 삭제하기 전에 모든 애플리케이션에서 새 키로 전환했는지 확인하세요.
</Warning>

## IP 화이트리스트

엔터프라이즈 플랜에서는 IP 화이트리스트 기능을 사용할 수 있습니다. 특정 IP 주소에서만 API 호출을 허용하여 보안을 강화할 수 있습니다.

## 요청 서명 (선택사항)

고급 보안이 필요한 경우 요청 서명을 사용할 수 있습니다. 자세한 내용은 [고급 인증 가이드](https://docs.huny.dev/advanced-auth)를 참고하세요.
