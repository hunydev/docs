---
title: '리소스 업데이트'
openapi: 'PUT /resources/{id}'
---

특정 리소스의 정보를 업데이트합니다.

## 요청 예시

<RequestExample>
```bash cURL
curl -X PUT 'https://api.huny.dev/v1/resources/res_1234567890' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "수정된 리소스 이름",
    "description": "수정된 설명"
  }'
```
</RequestExample>

## 경로 파라미터

<ParamField path="id" type="string" required>
업데이트할 리소스의 고유 ID입니다.
</ParamField>

## 요청 본문

<ParamField body="name" type="string">
리소스 이름입니다.
</ParamField>

<ParamField body="description" type="string">
리소스 설명입니다.
</ParamField>

<ParamField body="metadata" type="object">
추가 메타데이터입니다.
</ParamField>
