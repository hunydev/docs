---
title: '리소스 목록 조회'
openapi: 'GET /resources'
---

시스템에 등록된 모든 리소스 목록을 조회합니다.

## 요청 예시

<RequestExample>
```bash cURL
curl -X GET 'https://api.huny.dev/v1/resources?page=1&per_page=20&type=document' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```
</RequestExample>

## 쿼리 파라미터

<ParamField query="page" type="integer" default="1">
페이지 번호입니다.
</ParamField>

<ParamField query="per_page" type="integer" default="20">
페이지당 항목 수입니다. 최대 100까지 설정할 수 있습니다.
</ParamField>

<ParamField query="type" type="string">
리소스 타입으로 필터링합니다.
</ParamField>

## 응답 필드

<ResponseField name="data" type="array" required>
리소스 객체 배열입니다.

<Expandable title="Resource 객체">
  <ResponseField name="id" type="string" required>
  리소스 고유 ID입니다.
  </ResponseField>

  <ResponseField name="name" type="string" required>
  리소스 이름입니다.
  </ResponseField>

  <ResponseField name="type" type="string" required>
  리소스 타입입니다.
  </ResponseField>

  <ResponseField name="description" type="string">
  리소스 설명입니다.
  </ResponseField>

  <ResponseField name="metadata" type="object">
  추가 메타데이터입니다. 자유로운 형식의 키-값 쌍을 포함할 수 있습니다.
  </ResponseField>

  <ResponseField name="created_at" type="string" required>
  리소스 생성 일시입니다.
  </ResponseField>

  <ResponseField name="updated_at" type="string">
  리소스 수정 일시입니다.
  </ResponseField>
</Expandable>
</ResponseField>
