---
title: '사용자 생성'
openapi: 'POST /users'
---

새로운 사용자를 시스템에 등록합니다.

## 요청 예시

<RequestExample>
```bash cURL
curl -X POST 'https://api.huny.dev/v1/users' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "email": "newuser@example.com",
    "name": "새 사용자",
    "password": "secure_password_123",
    "role": "user"
  }'
```
</RequestExample>

## 요청 본문

<ParamField body="email" type="string" required>
사용자 이메일 주소입니다. 유효한 이메일 형식이어야 하며, 시스템 내에서 고유해야 합니다.
</ParamField>

<ParamField body="name" type="string" required>
사용자 이름입니다. 최소 2자 이상이어야 합니다.
</ParamField>

<ParamField body="password" type="string" required>
사용자 비밀번호입니다. 최소 8자 이상이어야 하며, 영문, 숫자, 특수문자를 포함하는 것을 권장합니다.
</ParamField>

<ParamField body="role" type="string" default="user">
사용자 역할입니다. 기본값은 `user`입니다.
</ParamField>

## 사용 예시

### JavaScript

```javascript
const response = await fetch('https://api.huny.dev/v1/users', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    email: 'newuser@example.com',
    name: '새 사용자',
    password: 'secure_password_123',
    role: 'user'
  })
});

const data = await response.json();
console.log(data);
```

### Python

```python
import requests

headers = {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
}

data = {
    'email': 'newuser@example.com',
    'name': '새 사용자',
    'password': 'secure_password_123',
    'role': 'user'
}

response = requests.post(
    'https://api.huny.dev/v1/users',
    headers=headers,
    json=data
)

print(response.json())
```

<Tip>
  비밀번호는 서버로 전송되기 전에 클라이언트 측에서 해시화하지 마세요. 서버에서 안전하게 처리됩니다.
</Tip>
