---
title: '사용자 삭제'
openapi: 'DELETE /users/{id}'
---

시스템에서 사용자를 삭제합니다. 이 작업은 되돌릴 수 없습니다.

## 요청 예시

<RequestExample>
```bash cURL
curl -X DELETE 'https://api.huny.dev/v1/users/usr_1234567890' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```
</RequestExample>

## 경로 파라미터

<ParamField path="id" type="string" required>
삭제할 사용자의 고유 ID입니다.
</ParamField>

## 성공 응답

성공적으로 삭제되면 `204 No Content` 상태 코드를 반환하며 응답 본문은 없습니다.

## 에러 응답

### 사용자를 찾을 수 없음

<ResponseExample>
```json Error Response (404)
{
  "error": {
    "code": "USER_NOT_FOUND",
    "message": "사용자를 찾을 수 없습니다.",
    "details": {
      "id": "usr_1234567890"
    }
  }
}
```
</ResponseExample>

### 권한 부족

<ResponseExample>
```json Error Response (403)
{
  "error": {
    "code": "FORBIDDEN",
    "message": "이 작업을 수행할 권한이 없습니다.",
    "details": {
      "required_permission": "users.delete"
    }
  }
}
```
</ResponseExample>

## 사용 예시

### JavaScript

```javascript
const response = await fetch('https://api.huny.dev/v1/users/usr_1234567890', {
  method: 'DELETE',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY'
  }
});

if (response.status === 204) {
  console.log('사용자가 성공적으로 삭제되었습니다.');
}
```

### Python

```python
import requests

headers = {
    'Authorization': 'Bearer YOUR_API_KEY'
}

response = requests.delete(
    'https://api.huny.dev/v1/users/usr_1234567890',
    headers=headers
)

if response.status_code == 204:
    print('사용자가 성공적으로 삭제되었습니다.')
```

<Warning>
  삭제 작업은 되돌릴 수 없습니다. 삭제하기 전에 신중하게 확인하세요. 대신 사용자를 비활성화하려면 상태를 `inactive`로 변경하는 것을 고려하세요.
</Warning>

<Tip>
  중요한 사용자의 경우, 삭제 대신 상태를 `suspended`로 변경하여 나중에 복구할 수 있도록 하는 것이 좋습니다.
</Tip>
