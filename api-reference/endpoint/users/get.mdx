---
title: '사용자 목록 조회'
openapi: 'GET /users'
---

사용자 목록을 조회합니다. 페이지네이션, 필터링, 정렬 기능을 지원합니다.

## 요청 예시

<RequestExample>
```bash cURL
curl -X GET 'https://api.huny.dev/v1/users?page=1&per_page=20&status=active' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```
</RequestExample>

## 쿼리 파라미터

<ParamField query="page" type="integer" default="1">
페이지 번호입니다. 1부터 시작합니다.
</ParamField>

<ParamField query="per_page" type="integer" default="20">
페이지당 반환할 항목 수입니다. 최대 100까지 설정할 수 있습니다.
</ParamField>

<ParamField query="status" type="string">
사용자 상태로 필터링합니다. 가능한 값: `active`, `inactive`, `suspended`
</ParamField>

<ParamField query="role" type="string">
사용자 역할로 필터링합니다.
</ParamField>

<ParamField query="sort" type="string" default="created_at">
정렬할 필드입니다. 가능한 값: `created_at`, `updated_at`, `name`, `email`
</ParamField>

<ParamField query="order" type="string" default="desc">
정렬 순서입니다. `asc` (오름차순) 또는 `desc` (내림차순)
</ParamField>

## 사용 예시

### 활성 사용자만 조회

```bash
curl -X GET 'https://api.huny.dev/v1/users?status=active' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```

### 이름순으로 정렬

```bash
curl -X GET 'https://api.huny.dev/v1/users?sort=name&order=asc' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```

### 관리자 역할 필터링

```bash
curl -X GET 'https://api.huny.dev/v1/users?role=admin' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```
