## 조직 API

조직 설정은 관리 UI 또는 `/v1/organizations/{org_id}` REST 엔드포인트로 제어할 수 있습니다.

<RequestExample>
```bash curl
curl -X PATCH "https://api.huny.dev/v1/organizations/org_c72a/settings" \
  -H "Authorization: Bearer $HUNY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "incident_routing": "pagerduty",
    "default_region": "ap-northeast-2",
    "data_retention_days": 90
  }'
```
</RequestExample>

<ResponseField name="incident_routing" type="string">
`slack`, `pagerduty`, `webhook`, `email` 중 하나. 모든 정책 위반이 우선 전달되는 채널입니다.
</ResponseField>

<ResponseField name="default_region" type="string" required>
신규 워크스페이스가 생성되는 기본 리전. `us-east-1`, `eu-west-1`, `ap-northeast-2` 를 지원합니다.
</ResponseField>

<ResponseField name="data_retention_days" type="integer">
원본 이벤트를 보존하는 기간. Starter 30, Scale 90, Enterprise 365일까지 확장 가능.
</ResponseField>

## 데이터 보존 및 거버넌스

- **Ingest 보존**: `data_retention_days`로 제어  
- **메트릭 보존**: 최대 400일(지표), 30일(세부 로그)  
- **PII 필터링**: 정책에서 `mask(payload.card_number)` 같은 함수를 사용하면 저장 전에 자동 마스킹

<AccordionGroup>
  <Accordion title="Legal hold">
    `POST /v1/legal-holds` 로 특정 스트림/레코드를 영구 보존 상태로 전환할 수 있습니다.
  </Accordion>
  <Accordion title="지역 격리">
    Huny는 데이터가 생성된 리전 밖으로 이동하지 않습니다. 다만 메타데이터(지표)는 전역에서 요약됩니다.
  </Accordion>
</AccordionGroup>

## 알림 채널

<Steps>
  <Step title="채널 등록">
    `POST /v1/notifications/channels` 로 대상 시스템을 등록합니다.
    
    <RequestExample>
    ```bash
    curl -X POST "https://api.huny.dev/v1/notifications/channels" \
      -H "Authorization: Bearer $HUNY_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "type": "webhook",
        "name": "On-call API",
        "config": {
          "url": "https://incident.example.com/huny",
          "secret": "whsec_xxx"
        }
      }'
    ```
    </RequestExample>
  </Step>
  <Step title="정책과 연결">
    정책 정의 시 `actions` 배열에 `notify.channel_id` 를 추가하면 됩니다. 여러 채널을 나열해 다중 전파를 구성할 수 있습니다.
  </Step>
  <Step title="전달 상태 확인">
    `GET /v1/notifications/deliveries?channel_id=chn_123` 로 최근 100건의 상태를 확인하거나 Dashboard > Automation 에서 필터링하세요.
  </Step>
</Steps>

<Tip>슬랙 채널을 사용할 경우 `chat:write` 권한이 있는 Huny 앱을 워크스페이스에 설치해야 합니다.</Tip>
