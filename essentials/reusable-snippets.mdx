## 왜 스니펫인가?

- 모든 페이지에서 동일한 **Authentication** 블록을 유지  
- 스트림 정책 예시, 웹훅 페이로드, SLA 표 등 반복 요소를 싱크  
- 다국어 문서에서도 동일한 JSON/코드 블록을 공유

## 제작 방법

<Steps>
  <Step title="snippets 디렉터리에 MDX 파일 생성">
    `snippets/alerts.mdx` 처럼 파일을 추가합니다. 기본 내보내기(default export)가 곧 스니펫 본문입니다.
  </Step>
  <Step title="콘텐츠 작성">
    ```mdx snippets/policy-example.mdx
    <CodeGroup>
    ```json Latency policy
    {
      "when": "payload.event == 'checkout.completed'",
      "enforce": ["max_latency(5000)"],
      "actions": ["notify.slack", "retry.ingest"]
    }
    ```
    </CodeGroup>
    ```
  </Step>
  <Step title="필요한 페이지에 임포트">
    ```mdx
    import PolicyExample from '/snippets/policy-example.mdx';
    
    ## 지연 정책 템플릿
    <PolicyExample />
    ```
  </Step>
</Steps>

<Warning>`snippets` 폴더 밖의 파일은 자동으로 렌더링되므로, 재사용할 콘텐츠는 반드시 해당 폴더에 위치시켜야 합니다.</Warning>

## 변수와 컴포넌트

```mdx snippets/constants.mdx
export const workspaceHeader = {
  name: 'Huny-Workspace',
  description: 'API 헤더로 전달하는 워크스페이스 ID'
};
```

```mdx
import { workspaceHeader } from '/snippets/constants.mdx';

<ParamField header={workspaceHeader.name} type="string">
  {workspaceHeader.description}
</ParamField>
```

컴포넌트 형태로도 확장할 수 있습니다.

```mdx snippets/webhook-card.mdx
export const WebhookCard = ({ url }) => (
  <Card title="Webhook 테스트" icon="arrow-up-right-from-square" href={url}>
    등록된 엔드포인트로 즉시 테스트 페이로드를 전송합니다.
  </Card>
);
```

```mdx
import { WebhookCard } from '/snippets/webhook-card.mdx';

<WebhookCard url="https://docs.huny.dev/automation/webhooks" />
```
