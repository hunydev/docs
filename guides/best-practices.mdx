### 요청 서명 (선택사항)

고급 보안이 필요한 경우 요청 서명을 사용하세요:

```javascript
const crypto = require('crypto');

function signRequest(method, path, body, secret) {
  const timestamp = Date.now();
  const message = `${method}${path}${timestamp}${JSON.stringify(body)}`;
  const signature = crypto
    .createHmac('sha256', secret)
    .update(message)
    .digest('hex');
  
  return { timestamp, signature };
}
```

## 성능 최적화

### 캐싱 활용

자주 변경되지 않는 데이터는 캐싱하세요:

```javascript
const cache = new Map();
const CACHE_TTL = 5 * 60 * 1000; // 5분

async function getCachedData(key, fetchFn) {
  const cached = cache.get(key);
  if (cached && Date.now() - cached.timestamp < CACHE_TTL) {
    return cached.data;
  }
  
  const data = await fetchFn();
  cache.set(key, { data, timestamp: Date.now() });
  return data;
}
```

### 페이지네이션 활용

큰 데이터셋을 처리할 때는 페이지네이션을 사용하세요:

```javascript
async function getAllUsers() {
  let page = 1;
  let allUsers = [];
  
  while (true) {
    const response = await fetch(
      `https://api.huny.dev/v1/users?page=${page}&per_page=100`
    );
    const data = await response.json();
    
    allUsers = allUsers.concat(data.data);
    
    if (!data.links.next) break;
    page++;
  }
  
  return allUsers;
}
```

## 에러 처리

### 재시도 로직

일시적인 오류에 대해서는 재시도 로직을 구현하세요:

```javascript
async function retryRequest(fn, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fn();
    } catch (error) {
      if (i === maxRetries - 1) throw error;
      
      // 지수 백오프
      const waitTime = Math.pow(2, i) * 1000;
      await new Promise(resolve => setTimeout(resolve, waitTime));
    }
  }
}
```

## 속도 제한 관리

### 요청 간격 조절

속도 제한을 피하기 위해 요청 간격을 조절하세요:

```javascript
class RateLimiter {
  constructor(requestsPerMinute) {
    this.delay = (60 * 1000) / requestsPerMinute;
    this.lastRequest = 0;
  }
  
  async wait() {
    const now = Date.now();
    const timeSinceLastRequest = now - this.lastRequest;
    
    if (timeSinceLastRequest < this.delay) {
      await new Promise(resolve => 
        setTimeout(resolve, this.delay - timeSinceLastRequest)
      );
    }
    
    this.lastRequest = Date.now();
  }
}

const limiter = new RateLimiter(60); // 분당 60회

async function makeRequest(url) {
  await limiter.wait();
  return fetch(url);
}
```
