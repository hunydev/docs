## Huny API에 오신 것을 환영합니다

Huny API는 현대적인 웹 애플리케이션과 모바일 앱을 위한 강력하고 안정적인 RESTful API 서비스입니다. 간단한 인증, 빠른 응답 시간, 그리고 포괄적인 문서화를 통해 개발자 경험을 최우선으로 합니다.

## 시작하기

<Steps>
<Step title="API 키 발급">
  대시보드에서 새 API 키를 생성하세요. 각 키는 고유한 권한과 속도 제한을 가집니다.
  
  <Check>
  API 키는 안전하게 보관하고 절대 공개 저장소에 커밋하지 마세요.
  </Check>
</Step>

<Step title="첫 API 호출">
  인증 헤더에 Bearer 토큰을 포함하여 첫 요청을 보내보세요.
  
  ```bash
  curl -X GET 'https://api.huny.dev/v1/users' \
    -H 'Authorization: Bearer YOUR_API_KEY'
  ```
</Step>

<Step title="응답 확인">
  JSON 형식의 구조화된 응답을 받게 됩니다. 에러 처리와 재시도 로직을 구현하세요.
</Step>
</Steps>
